# D2R_Mod_jcy 暗黑破坏神II：狱火重生 Mod

## 简介
* 本 MOD 基于 Will MOD ，整合了各种增强包，通过控制器可以自由调整配置，满足不同需求。

* 仅面向 Windows PC 用户，不支持手柄操作。

* 运行控制器程序：
  Mods/jcy/jcy 控制器.exe
  修改设置后点击 “应用设置” 保存配置，重启游戏后生效。
  
* 如果有疑虑，可以直接删除控制器程序，这不会影响 MOD 的默认功能；
  或者可以从代码仓库获取源码，自行打包使用。
  仓库地址：https://github.com/jcymeow/jcy

* 有任何问题或建议都可以来QQ群沟通
  QQ群:808507013

## 特点
* 与原版不同之处 
  生命/魔法球禁止点击 
    原版中 Ctrl+左键点击生命/魔法球, 可以打开/关闭读数
  生命/魔法球读数下移 
    原版中 生命/魔法球读数在球体上方
  隐藏任务提示按钮 
    原版中 触发任务后, 会弹出任务提示按钮
  超市三个超级精英增加了死亡特效音
    jcy\jcy.mpq\data\hd\global\sfx\monster\unique_death.flac 不喜欢可以直接删除


## 使用
* 请先下载页面中的全部附件，
  然后解压其中任意一个压缩包即可（内容是一样的）。

* 当需要更新 MOD 时，
  请先删除旧版本的 MOD 目录，
  再解压并使用最新版本，避免残留文件导致异常。

* 游戏设置, 勾选"额外的命令行参数"，需要在启动参数中加入以下内容：
  `-mod jcy -txt -w -assettestmode 1`
  其中：
  -mod jcy -txt 是 JCY MOD 必须的基础参数
  -w 表示 以窗口模式运行游戏（不需要可以删掉）
  -assettestmode 1 是 国服专用参数，用于将怪物死亡后的墓碑恢复为尸体
  请根据你自己的客户端版本和使用需求选择是否启用这些参数。
  每个参数之间必须用空格分隔，否则游戏无法正确识别。

* 控制器程序和 MOD 包是绑定在一起使用的，不能分开存放。
  请务必将控制器程序放在 MOD 目录内，并从以下位置运行：
  Diablo II Resurrected/Mods/jcy/jcy 控制器.exe
  如果在其他位置运行，程序将无法正确识别 MOD 文件。

* "配置路径" 打开配置路径目录, 查看配置文件

* "创建MOD链接" 如果有多个《暗黑破坏神 II：重制版》客户端, 点击该按钮选择游戏主目录, 即可创建一份MOD镜像

* Handle -- 杀进程用
   Handle 是一个实用工具，用于显示有关系统中任何进程的打开句柄的信息。 可以使用它查看打开了文件的程序，或查看程序的所有句柄的对象类型和名称。

* sync_data_version_for_chinese_server.bat
  同步国际服数据版本编号 到 jcy/jcy.mpq/data/globaldatabuild.txt
  来源 https://gist.githubusercontent.com/jcymeow/3781261d482005da57f7946321072e18/raw/3588f1a6a4481ee080c5e7edd6f7def6aa8bbd25/dataversionbuild.txt
